# Действующая редакция требований

Этот репозиторий содержит самостоятельную редакцию контракта `week-4.1`. Для выполнения и проверки недели 4 не нужны файлы из родительского каталога курса. Решение участника остаётся тем же repository, который развивался на неделях 1–3.

Источники требований:

1. [Условие задания](../task/assignment.md) задаёт обязательный результат.
2. [Полный контракт недели 4](05-week-4.md) задаёт архитектурные и recovery-инварианты.
3. [Контракт наблюдаемости](observability-contracts.md) задаёт точные health, metrics и trace seams.
4. [Внешние HTTP-контракты](external-contracts.md) сохраняют точные provider/receipt contracts недели 3.
5. [Конфигурация и запуск](configuration.md) задаёт Compose seam, переменные и test profile.
6. [Контур автопроверки](07-autocheck-outline.md) задаёт проверяемые сценарии.
7. [Рейтинг и стоп-факторы](06-rating-and-checks.md) задают единые основания приёмки.
8. [Machine-readable contracts](../contracts/course-1) являются нормативными для JSON payload/result.

При расхождении prose с JSON Schema для формы JSON действует schema. Контракты недель 1–3 продолжают действовать, если `week-4.1` явно их не расширяет.
